레쥬메 (Resume) — 출력 데이터 필드 명세

유저 원본 데이터 → Resume JSON 파싱 · resume.py · _SYS_KO / _SYS_EN 스키마 · generate() · main() envelope 반환 (ko|en 단일 payload)

필수 — LLM이 반드시 채워야 하는 값선택 — 비어있을 수 있는 값시스템 — LLM 출력과 무관하게 코드가 계산·강제 주입/덮어쓰기조건부 — 특정 상태일 때만 값이 채워지고 그 외엔 null

🧩 공통 반환 형식(envelope) — 모든 analyzer main()은 아래를 반환합니다. 성공: { "status":"success", "result":{…payload…} } · 실패: { "status":"error", "message":"…" }. 아래 02번 이후 필드는 전부 result 안쪽입니다. vector 필드 없음 — 이 기능은 임베딩 컬럼이 없습니다. result 안에는 status·vector 를 넣지 않습니다(계약 §3.6). schema_version은 tasks.py(백엔드)가 주입(§3.5).
01Envelope · metaroot

language='ko'|'en'(API 경계)이면 result=단일 레쥬메 payload. 'both'(CLI 전용)는 result={ko, en} 묶음. 유저 원본 데이터에서만 추출 — 없는 정보는 null/빈 배열 (Hallucination 금지).
