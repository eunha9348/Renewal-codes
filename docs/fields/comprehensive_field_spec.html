종합 분석 (Comprehensive) — 출력 데이터 필드 명세

종합 커리어 분석 (강점·냉정 진단 통합 v2.0) · comprehensive.py · build_system_prompt_comprehensive() · verify_* 검증 · main() envelope 반환

필수 — LLM이 반드시 채워야 하는 값선택 — 비어있을 수 있는 값시스템 — LLM 출력과 무관하게 코드가 계산·강제 주입/덮어쓰기조건부 — 특정 상태일 때만 값이 채워지고 그 외엔 null

🧩 공통 반환 형식(envelope) — 모든 analyzer main()은 아래를 반환합니다. 성공: { "status":"success", "result":{…payload…}, "vector":[…] } · 실패: { "status":"error", "message":"…" }. 아래 02번 이후 필드는 전부 result 안쪽입니다. vector — 임베딩 3072차원 배열. result 밖 별도 필드(개별·종합만). result 안에는 status·vector 를 넣지 않습니다(계약 §3.6). schema_version은 tasks.py(백엔드)가 주입(§3.5).
